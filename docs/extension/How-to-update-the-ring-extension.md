# How to update the Ring extension

The Ring extension is updated automatically by your browser. To make sure you have the latest version, follow the steps for your browser.

## Chrome / Edge

1. Go to `chrome://extensions` (or `edge://extensions`).
2. Turn on **Developer mode** if it is not already enabled.
3. Click **Update** to force extensions to update, or wait for the browser to update them automatically.

## Firefox

1. Open the menu and select **Add-ons and themes**.
2. Click the gear icon and select **Check for updates**.

## Safari

- Safari extensions update through the Mac App Store. Open the App Store, go to **Updates**, and update the Ring extension if it appears.
