title: Ring Swap v2 Deployments
---

Ring Swap v2 deployment addresses are maintained in the versioned
[Ring Protocol Contracts](/contracts/v2/deployments) page.

Use that page as a starting point for Ring Swap factories, Ring Swap routers, FewFactory, UniversalRouter,
Permit2, wrapper contracts, hook contracts, and init code hashes by network.

Verify the chain ID, bytecode, and relevant immutable references onchain before using an address. The table is not a
live registry, approval instruction, or deposit-address list.

Do not use upstream v2 deployment address tables for Ring Swap v2 integrations. Ring Swap v2
uses Ring deployments built around FewToken wrapping.
